## 🌱 PestGuardAI

**AI-Powered Crop Pest Detection & Risk Monitoring Platform**

PestGuardAI is an AI-powered agricultural application designed to
identify crop pests from images and provide confidence-based risk
assessment and recommendations.

### Key Features

- Image-based pest detection
- CNN-based image classification
- Confidence-based risk classification
- Pest-specific recommendations
- Real-time detection workflow
- Analytics dashboard
- Detection history and monitoring
- Voice alerts
- Responsive web interface

### Machine Learning

- Custom dataset containing **5,000+ images**
- **InceptionResNetV2** transfer learning
- OpenCV-based image preprocessing
- Confidence-based prediction handling

### Reported Model Performance

- Precision: **98.5%**
- Recall: **98.1%**

### Technology Stack

`Python` `TensorFlow` `Keras` `OpenCV` `FastAPI`
`React` `TypeScript` `MongoDB`
